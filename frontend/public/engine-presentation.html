Agentic core

Specialist nodes, one shared memory

Every node reads and writes a single InterviewState — the shared blackboard — so planning, evidence and reflection always agree with each other.

Loads the candidate's history, accumulates strengths, weaknesses and risk flags from evidence across sessions.

Judgment

Six dimensions, one composite score

Every answer is scored 0-10 with evidence citations, then weighted into a composite. The dimension label adapts to the field — Technical Knowledge for engineering, Domain Knowledge for anything else.

01

Domain / Technical Knowledge

Correctness of concepts, depth, terminology, awareness of trade-offs.

02

Communication

Clarity, structure, conciseness, ability to explain complex ideas simply.

03

Reasoning

Logical structure, alternatives considered, cause-effect analysis.

04

Behavioral

Teamwork, ownership, self-awareness, STAR-style evidence.

05

Confidence

Certainty, honest unknowns, no false expertise.

06

Completeness

Full coverage of the question, sub-parts, missing elements.

Hypothesis: untested → testing → confirmed or refuted → Hiring verdict + confidence
